# Web ARMS RUM 接入设计

## 范围与目标

仅接入 `Quanta-admin-web` 这一套 Web/H5 单页应用，覆盖入口、新生、塔员和管理页面；不改 UniApp、后端、登录和现有 `X-Trace-Id`。用户拒绝监控仍可正常使用网站。

## 接入方式

使用阿里云控制台提供的异步 CDN SDK。仅当生产构建部署于 `www.quantacenter.com` 时使用提供的杭州地域 `endpoint`，其 `service_id` 为 `d08n852dkz@a575525305e4ddb5ce019`。配置 `env: 'prod'`、`spaMode: 'history'`、所提供的性能、Web Vitals、接口、静态资源及错误采集项；行为采集使用更新后的 `click: { enable: true, trackUserInteractions: true }`，保持 `tracing: false`、`replay: false`。不新增 npm 依赖；开发、测试和本地预览环境不向生产应用上报。

## 用户选择与隐私

首次访问时显示不阻塞业务的隐私监控提示，明确可“同意”或“暂不同意”；两者均可继续使用网站。只有同意后才加载 SDK，并将选择保存在浏览器本地。全局保留轻量的“监控设置”入口以便再次修改选择；撤回后刷新页面以完全卸载 SDK。正式上线前应在网站隐私政策中披露阿里云用户体验监控 SDK 的用途和采集信息。

## 数据与故障边界

不向 RUM 主动设置学号、姓名、邮箱、令牌、简历内容或其他业务用户标识。尽量从上报的页面和资源 URL 中去除查询参数与片段，避免敏感字段进入遥测；不发送请求或响应体。SDK 加载失败不得影响页面或登录。现有 `X-Trace-Id` 仍由请求层负责，`tracing: false` 表示此阶段不启用 ARMS 分布式 Trace 关联。

## 验证

增加单元测试覆盖同意/拒绝/撤回、本地非生产环境不加载、重复初始化防护和加载失败不影响页面。运行现有 lint、Vitest 与构建；生产构建检查配置，浏览器中核对同意前无 SDK 请求、同意后产生上报、拒绝后业务可用。
